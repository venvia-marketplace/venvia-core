# Initial Core installation contract (draft 1)
Desk provisions an isolated runtime and verifies the approved Core archive before executing any migration. A release manifest identifies component id venvia-core, version, minimum PHP, supported MariaDB versions, archive SHA-256, signature and public entry point. Reject unsupported versions, untrusted signatures, absolute archive paths, traversal, links and reparse points.
The package must contain the complete reviewed Core 0.3 baseline, migrated to configurable paths, with no WordPress dependency. Do not replace the Core with the diagnostic probe.
Desk supplies protected instance configuration outside the document root, including absolute data root, database connection, canonical HTTPS Control URL and instance identifier. Credentials never enter URLs, command-line arguments or diagnostic reports. Database binds to loopback; application account has only privileges needed for normal operations. Provisioning/migrations use separately scoped privileges.
Before modification: check ownership, conflicts, disk capacity, backup/restore and rollback. Install into a fresh versioned directory; preserve data and identities; validate then activate atomically where possible. Existing installations must not be silently overwritten.
Initial technical administrator is created via protected setup, not shipped credentials; MFA and recovery keys mandatory. Preserve separation from operational administrator. All subsequent PHP plugins are installed by authorized Control Center operators according to policy, with staging and rollback.
Health: Nginx config syntax; real HTTPS request with chain/hostname verification; fixed PHP FastCGI probe; authenticated read-only SQL SELECT 1; Core version and setup readiness. A running port or process does not prove health. The CLI probe in tools can assist but cannot certify HTTP or Core readiness.
Acceptance includes previous 0.3 functionality, reboot, local offline operation, plugin lifecycle, backups, staging, and negative security tests. This contract is provisional until actual 0.3 sources are reviewed.
